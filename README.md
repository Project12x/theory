# Theory

A living catalog of Eric Steenwerth's philosophical, metaphysical, and physics-adjacent frameworks.

This repository is meant to hold more than finished essays. It is a map of a worldview in progress: core theses, speculative extensions, formalization attempts, open questions, fragments, and future research paths.

## How To Read This Repo

- Start with [wiki/index.md](wiki/index.md) for the Obsidian/Karpathy-style compiled wiki.
- Use [AGENTS.md](AGENTS.md) for the wiki schema and ingest/query rules.
- Use [catalog/INDEX.md](catalog/INDEX.md) as the earlier catalog layer; it is gradually superseded by `wiki/`.
- Use [templates/philosophy-entry.md](templates/philosophy-entry.md) when drafting a new philosophy, thesis, fragment, or research program outside the wiki.

## Current Source Texts

- [The Unbroken Line](unbroken_line_thesis_v15.md) - the large philosophical spine connecting symbols, magic, technology, institutions, consciousness, collapse, and cosmology.
- [CHPE](chpe_thesis_v_1.md) - a discrete adjacency-rewriting formalization of the cosmological/physics layer.
- [Cosmological Signal Processing](Cosmological%20Signal%20Processing%20in%20the%20Crystallized%20Probability%20Hypergraph.txt) - the newest compressed paper framing the universe as an emergent ADC hypergraph.

## Repository Goals

1. Preserve original source documents.
2. Catalog each philosophy by domain, maturity, core claims, and open questions.
3. Track recurring concepts across documents.
4. Separate finished prose from working notes and formalization attempts.
5. Make the worldview easier to extend, critique, and eventually publish.
6. Preserve provenance, especially the distinction between original authorial work and AI-assisted formalization.
