# New Entry Checklist

Use this when adding a new philosophy, thesis, fragment, or research program.

1. Create the source document or note.
2. Add it to [SOURCES.md](SOURCES.md).
3. Add a row in [INDEX.md](INDEX.md).
4. Add it to one or more domain pages under [domains](domains).
5. Add or update any relevant threads under [threads](threads).
6. If it introduces a reusable concept, create a concept entry under [concepts](concepts).
7. Add falsification or revision conditions when the idea makes claims about reality.
